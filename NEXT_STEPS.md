# NEXT STEPS — ISLE OF ORIGINS

## Prioridad 1 — Preparar el entorno
- [ ] Confirmar si Unreal Engine 5 funciona de forma aceptable en el equipo.
- [ ] Instalar y registrar la versión exacta del motor.
- [ ] Crear el proyecto base y probar que abre correctamente.
- [ ] Crear el repositorio Git con un `.gitignore` adecuado.
- [ ] Registrar decisiones en `TECHNICAL_DOCUMENTATION.md`.

## Prioridad 2 — Prototipo jugable
- [ ] Crear un mapa de prueba pequeño.
- [ ] Implementar personaje, movimiento y cámara.
- [ ] Añadir una interacción sencilla.
- [ ] Implementar un recurso recolectable.
- [ ] Crear un sistema básico de salud.
- [ ] Añadir un dinosaurio de prueba con IA sencilla.
- [ ] Probar el bucle: explorar, recolectar, detectar amenaza y sobrevivir.

## Prioridad 3 — Validación
- [ ] Ejecutar pruebas en el equipo objetivo.
- [ ] Medir FPS, RAM y VRAM.
- [ ] Corregir errores críticos.
- [ ] Documentar limitaciones y decisiones.

## Prioridad 4 — Ampliación
- [ ] Añadir inventario.
- [ ] Desarrollar una primera misión narrativa.
- [ ] Crear un laboratorio pequeño explorable.
- [ ] Añadir ciclo día/noche si el rendimiento lo permite.
- [ ] Evaluar multijugador después de validar el prototipo individual.

## Regla de priorización
No ampliar el mapa ni producir una gran cantidad de dinosaurios antes de tener un personaje controlable, una zona de prueba y un bucle jugable estable.
